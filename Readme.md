Scientific Paper Title Generator using GPT-2

This project is an AI-powered NLP system that automatically generates research paper titles by fine-tuning a GPT-2 language model on thousands of scientific article titles scraped from arXiv.org.

It demonstrates real-world applications of web scraping, natural language processing, transformer models, and model deployment.

🚀 Features

🔍 Scrapes 2,000+ research titles from arXiv using BeautifulSoup

🧹 Cleans and preprocesses real-world text data

🤖 Fine-tunes GPT-2 using HuggingFace Transformers

✨ Generates high-quality scientific paper titles

🌐 Ready for deployment with Flask web interface

☁️ Runs completely on Google Colab
Tech Stack
